# 《俞军产品方法论》Skill

> 俞军 著 | [cangjie-skill](https://github.com/kangarooking/cangjie-skill)(RIA-TV++ v2.5)蒸馏 | 18 张能力卡,单入口路由式

把俞军产品方法论的核心框架提炼为 agent 可调用的能力:用户价值公式、相对价格公式、交易模型(利从何来/利往何去)、效用四分类、权衡决策五步、判责弹簧、用户模型积累法等。

## 能力清单

| 能力 | 重要度 | 解决什么问题 |
| --- | --- | --- |
| 用户价值公式与三条提升路径 | critical | 评估产品/功能给用户创造的价值；分析用户为何不来或流失；定位目标人群与切换策略 |
| 相对价格公式与增长三杠杆 | critical | 分析增长停滞与转化率低的原因；排查未转化用户被什么阻断；在降价/加功能/简化流程之间做选择 |
| 交易模型设计 (利从何来/利往何去) | critical | 设计或评审商业模式/交易结构；设计多方利益分配 (抽成/补贴/定价/准入)；诊断业务不可持续或一方流失 |
| 效用四分类与满足策略 | high | 决定某类需求/功能做到什么程度；设定质量指标与验收标准；在修 bug 与做新功能间排优先级 |
| 理性决策三要素与价值判断九视角 | critical | 重要决策前的结构化自查；评估决策质量 (区分过程与结果)；难量化价值判断的权衡 |
| 三种决策方法 (数据/逻辑/主观判断) 的选择 | high | 决定是否用 AB 测试/数据驱动；选择说服他人的证据形式；无数据无逻辑时做方向判断 |
| 权衡决策五步流程 | critical | 多方利益冲突时设计规则；评估国外可行方案为何本地水土不服；规则上线后随环境变化重新设计 |
| 判责弹簧 (判责分离+平台承担+上游解决) | high | 设计纠纷判责与客服处理规则；设计先行赔付/垫付机制；用兜底成本推动上游改进 |
| 用户行为机制与五属性 | high | 解释反直觉的用户行为；定位行为干预点；判断该换人群还是改设计 |
| 用户模型积累法 | critical | 新接手产品快速建立用户理解；建立个人用户研究日常程序；评估用户研究结论的可迁移性 |
| 好产品三属性与需求发现 | high | 判断产品/需求是否值得立项；甄别真需求与伪需求；评审商业化方案的可持续性 |
| 产品经理面试选拔法 | high | 面试产品经理 (校招/社招/高阶)；评估产品经理能力与潜力；设计产品岗面试题库与简历筛选 |
| 产品经理成长路径 | high | 规划产品经理职业成长；在 offer/团队/路线间做选择；诊断当前环境是否利于成长 |
| 企业分析框架 | medium | 分析一家公司/竞品/潜在雇主；判断业务该扩张还是补短板；决定自己做还是投资/外包 |
| 推动决策落地 | medium | 推动正确方案在组织内落地；设计跨部门影响策略；与认知框架不同的人沟通 |
| 边际分析三件套 | medium | 判断商业模式的性质与弹性；做扩张/降价/补贴决策；测算客流量波动对利润的敏感性 |
| 产品经理价值与岗位价值公式 | medium | 评估 offer/跳槽决策；招聘定价与留存预判；评估空降/挖人成功率 |
| 俞军产品经理十二条 (2005 版) | medium | 快速自检产品决策/功能提案；产品新人入门原则清单；查阅俞军十二条原文 |

## 安装

```bash
./install.sh                      # 装到 ~/.zcode/skills/yujun-product-methodology
./install.sh ~/my-skills          # 或指定目录(FORCE=1 覆盖)
```

安装后 agent 在触发场景自动调用;也可直接阅读 `references/capabilities/` 下的能力卡,
每张卡为六段结构:R 原文摘引 / I 方法论骨架 / A1 书中应用 / A2 触发场景 / E 可执行步骤 / B 边界。
