# 决策规则速查 — 俞军产品方法论

| 能力 | 一句话规则 |
|---|---|
| 用户价值公式与三条提升路径 | 评估产品价值先比三项: 新体验 – 旧体验 – 替换成本, 再选主攻路径 |
| 相对价格公式与增长三杠杆 | 增长只有三个杠杆: 增效用组合、降直接成本、降交易成本 |
| 交易模型设计 (利从何来/利往何去) | 设计机制先答两问: 利从何来 (创造), 利往何去 (分配), 再过三检验 |
| 效用四分类与满足策略 | 需求分四类投入: 底线清零 bad case, 够用即停, 越多做到均衡, 惊喜适量 |
| 理性决策三要素与价值判断九视角 | 先校准信念, 再批判目标, 最后才找方案; 权衡过九视角再定 |
| 三种决策方法 (数据/逻辑/主观判断) 的选择 | 判题型选方法: 能实验用数据, 认知匹配讲逻辑, 方向判断靠模型推演 |
| 权衡决策五步流程 | 权衡五步: 拆本质、列约束、译价值观、选相对最优、MVP 后迭代 |
| 判责弹簧 (判责分离+平台承担+上游解决) | 判责别二值: 分离双方责任, 判不清平台兜底, 根因推上游 |
| 用户行为机制与五属性 | 行为 = 情境刺激 × 偏好认知 → 期望效用 → 行为 → 经验反馈; 人有五属性 |
| 用户模型积累法 | 以情境为单位攒样本, 形成分布模型, 用预判命中率检验 |
| 好产品三属性与需求发现 | 好产品 = 有效用 + 有收益 + 可持续; 需求只能发现不能创造 |
| 产品经理面试选拔法 | 面试两问 (深挖做过的事+陌生题拆解), 潜力三判, 自省第一 |
| 产品经理成长路径 | 先达合格线 (用户模型) 再进阶 (交易模型); 选环境看五要素, 选择前算目标与代价 |
| 企业分析框架 | 看企业先问两件事: 钱从哪来 (机会), 凭什么比市场强 (效率) |
| 推动决策落地 | 推动力 = 为他人创造价值的能力; 按对方认知结构设计沟通, 议程设置慎用 |
| 边际分析三件套 | 看"再多一单": 边际成本先降后升, 边际利润决定生意弹性 |
| 产品经理价值与岗位价值公式 | 个人价值 = 经验×平台匹配×智慧 (相乘, 一项趋零全趋零); 岗位价值 = 事×成功率×回报 |
| 俞军产品经理十二条 (2005 版) | 2005 版十二原则: 首先是用户、体验是完整过程、不做什么更重要、迎合不教育 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
