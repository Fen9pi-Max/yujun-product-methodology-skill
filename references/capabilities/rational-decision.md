# 理性决策三要素与价值判断九视角

## R — Reading (原文)

> "理性决策的三要素, 按重要性由高到低依次是: 理性的信念、理性的目标、理性的行动。……理性的信念即与真实世界一致的信念, 也可以理解成'对自我认知的认知'。……理性的目标应该是约束条件下的价值 (总效用) 最大化。……理性的行动是在给定目标下, 寻找最优解决方案。"
> —— 4.1.2《理性决策的三要素》

配套九视角 (2.5.3 / 4.1.4 两处列举一致): "对自我认知的认知; 对给定目标的批判性思考; 参照系; 成本; 不确定性决策; 概率 (风险决策); 非货币价值 (跨效用决策); 外部性; 时间性 (跨期决策)。" 以及 (预期效用 = (收益–各种成本)×概率) 与 "结论可以错, 逻辑不能错" (附录·湖畔讲座)。

## I — Interpretation (自述)

决策质量分三层, 重要性从上到下: 先校准信念 (我对这件事的认知打几分? 有哪些偏差? 值得花多少成本补什么信息?)——"人类最大的理性, 是理性地理解自身认知能力的局限性"; 再批判目标 (这个目标本身理性吗? 关键约束变了吗? 为什么不是别的目标?)——目标错了, 错误目标下的最优解跑得越快错得越多; 最后才是找方案 (多数人只在这一层打转)。价值判断难量化时, 用九个视角过一遍: 自我认知、目标批判、参照系 (不公平感/满意度由参照系决定)、成本 (直接/交易/机会/风险四类一起算, "只谈收益或只谈成本的不是骗子就是傻瓜")、不确定性、概率 ((收益–成本)×概率=预期效用, 才可比)、非货币价值 (跨属性权衡)、外部性 (第三方与冲突目标)、时间性 (3 个月对 vs 3 年错)。评价思考过程时: 结论可以错, 逻辑不能错——逻辑链断了, 失败后无从定位问题。

## A1 — Application Example (书中案例 / 合成演练)

【书中案例 · 原书论述, 出处 4.1.2】"现实中, 没有刻意训练过的产品经理, 大多数人都仅徘徊于第三项: 寻找最优解决方案。但前两项更重要……目标如果错了, 在错误的目标下得到的最优解, 跑得越快, 也只是错得更多。"

【书中案例 · reported_case, 出处 4.1.4 (时间性+外部性)】用户抽烟/暴食/沉溺短视频: 以 3 个月为时间标准评价是自愿快乐的, 以 3 年评价则很可能后悔——"你的决策者会选择 3 个月还是 3 年?"

【合成演练 (原书未提供, 按其规则构造)】"工具 App 要不要加开屏广告": 信念层 (我对用户广告容忍度的认知几分? 有无留存-广告弹性数据? 可能的偏差: 创收压力下的证实偏见) → 目标层 (目标是季度营收还是 3 年 DAU×LTV? 约束变了没?) → 行动层 (方案比较) → 九视角抽三: 参照系 (用户对标无广告竞品)、时间性 (3 个月收入 vs 3 年留存)、外部性 (广告主质量伤害用户)。输出: 三层检查记录+至少三视角应用+预期效用粗估。

## A2 — Future Trigger (触发情境)

1. 重要产品决策前的自查 ("这个方向对不对, 我的判断可靠吗")
2. 决策评审/复盘: 评估一个决策的质量 (而非只看结果)
3. 各方价值判断不一致、难量化时的权衡框架
4. 发现团队"直接进入方案讨论"时的踩刹车动作

语言信号: "这个决策靠谱吗""我的判断有多准""目标是不是错了""风险多大、概率呢""怎么权衡""短期 vs 长期" (中英: rational decision, expected utility, time horizon, trade-off, critical thinking)

与相邻能力的区分 (阶段 3 定稿): 本卡是决策的"质量结构" (信念-目标-行动+九视角); "用数据/逻辑/直觉哪种方法"见 decision-method-selection; "多方利益规则怎么定"见 trade-off-decision-process; 认知偏误清单是本卡信念层的敌人, 已并入本卡使用说明。

**AI 产品化适配** (AI 适配, 非原书) 追加触发情境: ① "agent 给的分析报告能直接信吗"——AI 生成材料进入信念层时的核验动作; ② "与 agent 结对做决策, 人在哪一层必须亲自动手"——目标批判与价值判断不外包。

## E — Execution (可执行步骤)

输入契约: 一个待决策问题 (表述为"在 A 与 B 之间选/是否做 X") + 决策者可接受的时间尺度。缺时间尺度时必须先问 (1 年还是 3 年会改变结论)。

1. 信念检查 (完成标准: 写出认知自评分 0-10 + 依据 + 已识别的偏差): 我对该问题所需信息的掌握程度? 值得花多少成本补哪些信息? 我可能有哪些认知偏误 (对照高发清单: 证实偏见/锚定/可得性/自利归因)?
2. 目标批判: 这个目标为什么是它? 不能是其他目标吗? 从确定目标到现在, 什么关键约束已变/将变? (若目标被推翻 → 回到目标重设, 不进第 3 步)
3. 方案与预期效用: 列各方案, 按 (收益 – 直接/交易/机会/风险成本) × 概率 粗估预期效用; 至少对三个方案成立才可比。
4. 九视角扫描 (至少过 5 项, 完成标准: 每项一句结论或"无影响"): 参照系 / 成本 / 不确定性 / 概率 / 非货币 / 外部性 / 时间性 / 自我认知 / 目标批判 (1-2 已覆盖)。
5. 输出决策记录: 三层检查 + 预期效用表 + 所选方案 + "逻辑链摘要" (供事后检验: 结论可以错, 逻辑不能错)。

判停点: 第 1 步认知自评 ≤3/10 且补信息成本可承受 → 先补信息再决策; 第 2 步目标被推翻 → 重写目标后重来。

输出契约: 一份结构化决策记录 (信念/目标/行动三层 + 九视角扫描 + 预期效用粗估); 完成标准 = 三层均非空、预期效用至少三个方案、时间尺度显式。

**AI 产品化适配** 要点 (AI 适配, 非原书):
1. 信念检查追加一条: 本决策引用的证据中哪些来自 AI 生成 (报告/数据/检索)? 逐条标注核验状态 (已溯源/未溯源), 未溯源的不计入信念依据。
2. 目标批判与价值观翻译不外包给 agent: agent 可列候选方案与推演, "目标为什么是它、不能是别的目标吗"必须由人写出答案。
3. 预期效用粗估中 AI 给出的数值一律附口径与区间, 不用点估计冒充; 概率判断由人复核后采用。
4. 决策记录的"逻辑链摘要"手写: 事后检验依赖的是人的逻辑链, 不是 agent 输出存档。
5. 完成标准: AI 来源证据全部有核验标注, 目标层结论有手写依据。

## B — Boundary (边界)

- 理性属于方法, 只能提高决策质量, 不能保证结果正确 (5.1.3: 未来取决于他人的行为和世界的变化; "通过理性推理得出正确的个人选择"需多年后回看且判断逻辑已含全部关键变量)。
- 不是所有事都值得走全流程: 不确定性过大、或理性思考的时间成本对结果影响过大的事, 以及日常琐事 (系统 1 的合理辖区), 不要过度仪式化。
- "不存在客观事实, 只有各自认为的事实"用于沟通场景 (见 decision-landing), 不要滑向相对主义拒绝一切证据。
- 预期效用公式对低频重大事件 (概率极小、单次不可重复) 的指导力弱, 书中尊重不确定性的态度优先于假精确。
- 相邻易混: 数据/逻辑/主观判断三种方法的选择 (decision-method-selection) 是本卡行动层的执行手段; 偏误清单是自检素材不是能力本身。
- 作者立场提醒: 俞军决策观形成于高迭代可实验的平台环境, 低迭代业务 (硬件/长周期 B 端) 中"快速验证修正"环节要替换为更重的预判。
- **AI 产品化适配** (AI 适配, 非原书): 不要因 agent 产出流畅完整就上调信念自评分——流畅度不是证据强度; AI 检索与分析的速度优势容易诱导跳过目标层直接比方案, 恰是本卡要防的"第三层徘徊"新形态。
