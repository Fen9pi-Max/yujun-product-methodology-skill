# 产品经理成长路径: 合格线 → 进阶

## R — Reading (原文)

> "我们把'掌握一个领域的用户模型'视为产品经理的合格线, 而把交易模型设计视为产品经理的进阶之路。" (1.3.4)
> "刚入行时别想着找大机遇一飞冲天, 而是要看哪里有大量迭代, 能从无数的实践中学习和积累经验。……产品经理的学习必然是阅读、思考、实践三位一体的, 其中最短板决定你的上限。" (5.2.2)
> "如果有机会, 可以发展这六个方面的能力: 从 0 到 1, 做深做透, 做宽做杂, 大用户量, 商业闭环, 团队建设。" (5.2.2)
> "一个东西对一个人的价值有多大……只在于他愿意为它付出什么代价。" (5.2.6)

## I — Interpretation (自述)

成长的双标准: 先达到合格线 (用户模型——见专门能力卡), 再进阶到交易模型 (创造有利可图的用户价值)。三视角自检: 科学方法 (逻辑/概率/控制实验/理性决策/经济学, 可学习)、人文关怀 (用户样本量/同理心/心理学/进化论/博弈论)、实践精神 (事实/数据/观察/权衡/反馈/迭代/自省); 只学一个就学批判性思维。前五年两原则: 去有大量迭代的地方 (没思考过的经历只是经历不等于经验), 加入有产品心的小团队 (直接汇报者和天天讨论的同伴比公司名气重要; 大厂成熟产品的"黄金螺丝钉"不是好环境); 六能力进阶——从 0 到 1 (做一次就够, 边际收益快速递减)、做深做透 (大公司细分场景)、做宽做杂 (中小公司多面手)、大用户量 (微小改动的反馈密度才够)、商业闭环 (没思考过赚钱的产品经理视野有缺陷)、团队建设 (前三年别过早做管理)。五年后四路线: 专业 (权衡决策/交易模型)、管理 (识人用人/分优先级, "找一个优秀下属比提升自己优先级更高")、业务 (同领域积累/to B 求稳)、新产品或创业 (天赋平平者机会成本低反而有比较优势; 优秀者应选后期业务); 另有出海。选环境五要素: 逻辑、同理心、经验、异见、数据。一切选择前先自问: 我想要什么, 愿意为此付出什么代价 (直接/交易/机会成本)。

## A1 — Application Example (书中案例 / 合成演练)

【书中案例 · firsthand, 出处 5.2.2 与附录】俞军 2001-2003 在百度是唯一产品经理, 两年经历网页/MP3/图片/新闻搜索全部从 0 到 1 与高速竞争——"哪里有一堆成长性产品, 哪里的产品经理就在快速崛起"; 零经验新人团队 (边江、李明远等) 随后经历贴吧、知道、百科的成长。

【书中案例 · firsthand, 出处 5.2.3】醉酒高级管理者求指点"一直在努力提升自己", 俞军: "你为什么要做'提升自己'这么艰难的事呢?……最简单有效的方法, 当然是全力找优秀人才做下属。找到一个就能少费心一半。"——管理路线的优先级排序示范。

【合成演练 (原书未提供, 按其规则构造)】工作 4 年 PM 在"大厂成熟业务细分方向"与"创业公司从 0 到 1"间选择: 定位 (前五年窗口期, 实践积累优先) → 六能力盘点 (缺从 0 到 1 与大用户量) → 路线匹配 (自评天赋中等 → 早期业务有比较优势; 若自评优秀 → 后期业务机会成本更低) → 目标-代价表 (1 年/3-5 年/10 年目标 + 愿付代价三类成本) → 结论记录。

## A2 — Future Trigger (触发情境)

1. 职业迷茫: "产品经理五年后怎么办""会不会失业"
2. 选 offer/选团队 ("大厂还是创业""跟谁更重要")
3. 制定年度成长计划 / 判断当前环境是否利于成长
4. 决定要不要转管理、要不要换业务

语言信号: "产品经理成长""职业规划""选 offer""带团队还是做专业""成长瓶颈""要不要创业" (中英: product manager career, growth path, offer decision, management track vs IC track)

与相邻能力的区分 (阶段 3 定稿): 本卡管"怎么成长与选择路线"; 具体岗位的估值公式见 pm-value-formula; 用户模型的积累程序见 user-model-accumulation (本卡合格线的落地); 面试他人见 pm-hiring。

**AI 产品化适配** (AI 适配, 非原书) 追加触发情境: ① "AI 会不会取代产品经理、五年后这岗位还剩什么"——执行熟练度贬值、判断力稀缺下的路线重估; ② "怎么把用 agent 变成成长加速器而不是拐杖"——样本处理提效与判断力保持的分工。

## E — Execution (可执行步骤)

输入契约: 个人现状 (年限/当前业务/团队情况) + 一个待决策的成长问题 (或"无具体问题、要年度盘点"——则做诊断版)。

1. 定位阶段: 入行 ≤5 年 (前五年窗口: 两原则+六能力盘点) / >5 年 (四路线选择)。完成标准: 写出当前所处阶段与依据。
2. 环境诊断 (五要素逐项): 逻辑 / 同理心 / 经验 (阅读+经历+思考三位一体, 最短板在哪) / 异见 (有无否定性意见文化) / 数据; 对照不利环境清单 (短期利益导向/迭代周期长/用户量少/分工过细/上级不会深度思考等) 标记中招项。
3. 能力盘点 (前五年): 六能力逐项 已有/缺失/机会在哪; 缺项能否在当前环境补, 不能则环境调整进入议程。
4. 路线匹配 (五年后): 专业/管理/业务/新产品/出海, 用两个判据——自身天赋评估 (以其他好产品经理的评价为准, 不自说自话) + 机会成本 (优秀→低风险后期业务; 平平→早期高风险业务有比较优势)。
5. 目标-代价表: 写 1 年/3-5 年/10 年目标, 每个目标列愿付的直接成本、交易成本、机会成本; 与当前选择对照 (别人没有义务为你的情怀付代价)。
6. 输出: 成长诊断报告 (阶段/环境/能力/路线/目标-代价) + 下一步动作 (≤3 条)。

判停点: 目标-代价表出现"想要但不愿付任何代价"项 → 该目标不是真目标, 删除后重排。

输出契约: 成长诊断报告; 完成标准 = 五节齐备且路线选择有天赋评估与机会成本两个依据。

**AI 产品化适配** 要点 (AI 适配, 非原书):
1. 环境诊断追加一条: 该环境用 agent 放大了判断 (人定方向、AI 执行) 还是替代了判断 (AI 出方案、人背书)? 后者是"黄金螺丝钉"的新变种, 标记为不利环境。
2. 六能力按 AI 时代重注: 从 0 到 1 与商业闭环权重升 (执行成本被 AI 拉低后, 判断与交易模型设计更稀缺), 执行类熟练度贬值加快, 学习投入相应重配。
3. 样本积累程序嫁接 agent: 用 AI 提高样本处理量, 但分布判断与预判命中率仍按 user-model-accumulation 的口径执行。
4. 目标-代价表追加一项: 为保持判断力愿付的代价 (亲手做关键权衡/定期脱离 AI 独立推演); 无此项的"提效"目标易滑为能力空心化。
5. 完成标准: 诊断报告五节含 AI 环境判据, 路线选择说明判断力如何随该路线增值。

## B — Boundary (边界)

- 路线判断强依赖自我认知: "最优选择只有自己能选"——本卡给判据不给答案; 天赋评估须以外部 (其他好产品经理) 评价为准。
- 时代约束: 书写于 2019 移动红利尾声, "新产品骤减"判断已被其后的 AI 周期部分改变; 四路线的适用性需按当前行业周期重估 (阶段 0 批判)。
- "过早做管理是减分项"针对成长效率而非管理价值; 有管理天赋或得力下属者例外 (原文有例外条款)。
- 高投入文化预设: 作者以身作则每周 100 小时, 属个人目标-代价选择, 不是普适要求; 引用时按"目标决定代价"逻辑呈现, 避免加班叙事。
- to B/出海等判断基于 2019 年市场; 数据 (薪酬分级 50/100/200 万) 有时效性。
- 相邻易混: 岗位估值用 pm-value-formula; 面试官视角见 pm-hiring。
- **AI 产品化适配** (AI 适配, 非原书): 不要把"会用 agent"当成第六种独立能力去单独补课——它放大已有判断力, 替代不了用户模型与交易模型的积累; 原书"三位一体最短板决定上限"在 AI 时代更可能短在判断, 而不是短在工具。
