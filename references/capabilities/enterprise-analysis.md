# 企业分析框架: 本质两问 + 詹森生产函数 + 发展生存 + 四产出

## R — Reading (原文)

> "总体上, 企业的本质, 只在于两点: 第一, 发现市场获利机会; 第二, 生产效率高于市场。" (2.4)
> "Q = Fr (L, K, M, C : T)" (2.4.7 詹森生产函数; "对产量 Q 的影响, 外部规则远大于技术。技术的影响又远大于其他要素。……长期来说, 内部规则的影响远大于劳动力、资本、原材料")
> "发展和生存是企业的两条腿。……发展是创造用户价值的游戏, 从任何角度突破都可以。……但生存是不能有短板的游戏。" (2.4.4)
> "企业做一个产品, 一般有四方面产出: 财务绩效; 认知; 团队; 无形资产。" (2.4.5)

## I — Interpretation (自述)

分析一家企业/一个业务的三层工具: ① 本质两问——钱从哪来 (发现获利机会: 洞察=信息不对称 / 试错=信息不完备 / 偶然性=信息不确定, 三者纠缠; 大机会三来源=环境制度变化/关键新技术/组织建设能力) 和凭什么比市场强 (生产效率高于市场, 靠权威与共同知识; 组织四要素=共同目标/理念/知识/运行机制)。② 詹森生产函数 Q=Fr(L,K,M,C:T)——产量先是外部规则 r 的函数 (政治法律社会等游戏规则决定产出边界, 规则换代期是冒险最佳时机), 再是技术 T 的函数 (新技术应用期同理), 长期看内部规则 C 的影响大于劳动力/资本/原材料; "分析企业其实就是分析产品"。③ 发展与生存两条腿——发展只看做成了什么, 生存不能有短板 (环境选择/替代成本/效率三项要点, 一个没处理好就可能致命)。另有: 做产品的四产出 (财务绩效/认知/团队/无形资产, 后三项即使产品失败也积累——所以"为投资放弃自己做产品"损失的是核心资产) 与团队质量的"一进一出"外部观测法。

## A1 — Application Example (书中案例 / 合成演练)

【书中案例 · reported_case, 出处 2.4.1】BAT 的偶然性: 马化腾曾想 50 万卖掉 QQ (没人买); 阿里早期的 1688 业务现有价值或不足总值的 1%; 百度创业后前三个业务 (搜索技术供应商/企业搜索数据库/CDN) 早已烟消云散——信息不确定下结果必然有偶然性。

【书中案例 · reported_case, 出处 2.4.8】英国王室势弱被迫签约 (禁止自由加税/没收财产), 产权保障激励几代商业冒险 → 工业革命水到渠成; 同期可横征暴敛的法国无此激励——制度 (外部规则) 决定长期产出。

【合成演练 (原书未提供, 按其规则构造)】社区连锁咖啡品牌: 本质两问 (获利机会=社区选址认知的洞察? 效率=供应链+店长培养体系高于单体咖啡馆?) → 詹森变量 (外部规则: 食安监管/租金; 技术: 自动化设备; 内部规则: 加盟激励设计) → 发展 vs 生存 (扩张看单店模型, 生存短板=食安一票否决) → 四产出盘点 (即使单店失败, 认知与团队保留)。

## A2 — Future Trigger (触发情境)

1. 研究一家公司/竞品/潜在雇主 ("这家公司凭什么活着/能活多久")
2. 判断业务该扩张还是补短板
3. 决定"自己做还是投资/外包"某个产品
4. 评估团队与组织质量

语言信号: "企业分析""商业模式护城河""为什么这么强""会不会倒""自己做还是投资""组织能力" (中英: company analysis, moat, organizational capability, growth vs survival, make vs invest)

与相邻能力的区分 (阶段 3 定稿): 本卡分析"组织与企业"层; 产品/需求层的立项判定见 product-value-judgment; 利益机制设计见 transaction-model-design; 找工作视角的团队选择见 pm-growth-path。与通用商业分析的区别: 以交易费用与制度经济学为轴 (权威/共同知识/相对规则)。

**AI 产品化适配** (AI 适配, 非原书) 追加触发情境: ① "这家 AI 公司凭什么活着——模型、数据还是场景"——获利机会来源对号 (洞察 vs 仅用新模型); ② "大模型会不会把我们这个行业的企业重写一遍"——詹森变量中技术 T 的权重重排。

## E — Execution (可执行步骤)

输入契约: 一家可描述的企业/业务 (有其产品、收入来源与组织的基本信息)。

1. 本质两问 (每问写结论+依据):
   - 获利机会来源标注: 洞察 (什么信息差) / 试错 (哪些尝试在跑) / 偶然性 (结果中不可归因部分), 并标大机会来源 (制度变化/新技术/组织能力);
   - 效率优势定位: 靠什么权威与共同知识做到"高于市场"? 关键岗位人才流失率与共同知识含金量如何?
2. 詹森变量扫描: 外部规则 (监管/准入/产权) 给的边界与近期变化 → 技术边界与换代窗口 → 长期看内部规则 (激励/文化/组织形式) 与要素投入的相对权重。完成标准: 三层各一句结论。
3. 两条腿体检: 发展侧列最近做成了什么; 生存侧按 环境选择/替代成本/效率 三项找短板 (任一短板标记风险等级)。
4. 四产出盘点: 该业务在 财务绩效/认知/团队/无形资产 上的积累状况; 判断"投资替代自建"是否损失后三项。
5. (可选) 团队质量外部观测: 优秀人才的进 (手握多 offer 者的选择) 与出 (离开者是否市场最受欢迎)。
6. 输出: 企业分析四件套报告。

判停点: 第 1 问答不出获利机会来源 (既非洞察也无试错在跑) → 如实输出"机会来源不明", 提示靠偶然性支撑的业务风险。

输出契约: 分析报告 (两问/詹森/两条腿/四产出); 完成标准 = 每节有结论与依据, 生存短板显式列出。

**AI 产品化适配** 要点 (AI 适配, 非原书):
1. 詹森变量重排: LLM 期技术变量 T 前移为产出边界的直接约束 (原框架中 T 已排在内部规则之前的第二层, 此处指其权重进一步上升); 新增隐性要素——专有数据与算力/部署能力, 分别登记进要素与内部规则两栏。
2. 获利机会对号检验: 该企业的机会是洞察 (独有场景/数据/分发) 还是仅"用了新模型"? 后者无效率优势, 随模型商品化归零。
3. 共同知识重定义: AI 时代组织共同知识新增"人机协作流程" (提示词资产/评测集/工作流); 四产出盘点时把评测集与数据资产计入无形资产。
4. 两条腿体检追加两项生存短板: 模型供应商依赖 (断供/涨价/能力退化) 与数据/安全合规, 任一致命即标红。
5. 完成标准: 四件套报告含 T 变量重排依据与供应商依赖结论。

## B — Boundary (边界)

- 詹森函数是 20 世纪 70 年代模型, 作者自己列出局限: 未考虑极低边际成本、网络效应、双边平台、知识工作者等互联网特征, 且只讲"生产"不讲"价值发现"——用它做框架, 不做精确计算。
- "发展只看成败、生存不能有短板"是评估口径的简化: 现实中发展期的严重错误也会摧毁生存, 两腿互为条件。
- 偶然性提醒贯穿: 分析结论是概率性的, 不要把幸存者叙事当因果 (配套三维归因)。
- 四产出的"即使失败也积累"以团队不散为前提; 关键员工离职带走默会知识即损失。
- 作者盲点提醒: 框架视角偏互联网平台企业; 分析传统制造业/国企时外部规则变量的权重需大幅上调。
- 相邻易混: 岗位选择 (个人视角) 见 pm-value-formula; 多边利益机制见 transaction-model-design。
- **AI 产品化适配** (AI 适配, 非原书): 詹森函数仍按原卡边界作框架、不作精确计算——不要因"AI 改变生产函数"就宣称可量化预测; 分析 AI 公司时风口期幸存者叙事更浓, 偶然性权重只升不降。
