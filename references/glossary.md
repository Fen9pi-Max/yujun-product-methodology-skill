# GLOSSARY — 俞军产品方法论 共享术语词典 (阶段 3 产出)

> 来源: candidates/glossary.md (25 条候选, 词频经脚本预筛)。所有能力卡与 DIGEST 共用本词典口径。
> 已复制到 .cangjie/capabilities/book/glossary.md 随编译分发。

| 术语 | 作者的用法 (含原文) | 与常识用法的差异 |
|---|---|---|
| 用户 | "用户不是自然人, 而是需求的集合。当某个产品完全满足了某个用户在某个场景下的某类需求, 那么就可以说此用户是该产品的一个用户。" (2.2.1) | ≠ 自然人/注册用户/DAU; 100 次专车需求只用 50 次滴滴 = 半个用户 |
| 用户价值 | 由买方主观效用评价定义; "用户价值 = 新体验 – 旧体验 – 替换成本"; "不是一个真的可以用加减法运算的公式" (2.2.3, 4.1.4) | ≠ 功能/属性/质量; 主观感知, 认知依存、情境依存、经验反馈演化 |
| 交易 (广义) | "'产品即交易'里的'交易', 是指把人的任何有意识行为, 看作付出预期代价购买预期收益。" (2.5.1) | ≠ 仅货币买卖; 作者自承认与传统经济学定义不一致, "更接近一种交换行为" |
| 产品即交易 | 企业以产品为媒介与用户交换价值; 用户的每次主动行为都是与世界的一次交易 (2.5, 3.1) | 产品不是功能集合而是价值交换媒介; 信息产品是货币价格为零的特殊交易 |
| 交易模型 | "促成用户做出某种行为且可持续的合理机制……设计精髓是'如何创造利益 (利从何来)'及'如何分配利益 (利往何去)'。" (3.1.2) | ≈ 商业模式但更广: 多边利益创造与分配, 利益不只是钱; 产品经理的"进阶"标准 |
| 用户模型 | "用户和潜在用户的偏好和行为反应模型……掌握的标志是: 预判产品迭代后的用户行为变化, 准确率较高。" (1.3.3) | ≠ 用户画像/问卷; 以预判命中率为检验标准的分布模型; 产品经理的"合格线" |
| 效用 | "效用是欲望的满足程度" (3.2.1); 心理上的主观评价, 特定个体特定情境; 产品提供的是效用组合 | ≠ 客观功能; 多样 (货币/时间/身体/心理/信念/情绪/认知) 且可无限叠加; 幸福=效用÷欲望 |
| 替换成本 | 认知成本、获取成本、使用成本; "广义来说, 价格和所有交易成本也都是替换成本" (4.1.4) | ≠ 仅迁移费; "缩小包体、简单易用……都是在降价" (非货币价格) |
| 交易成本 | "所有用户 (买方) 付出的但企业 (卖方) 收不到的成本, 以及所有企业付出但用户收不到的成本" (3.4.2); 市场型三类: 搜寻度量/寻价决策/实施保障 | ≠ 手续费; 来源四归因: 信息不对称/不确定/不完全/有成本 |
| 相对价格 (人间第一定律) | "相对价格 = (直接成本 + 交易成本) ÷ 效用组合"; 相对价格降低需求量上升 (3.6) | ≠ 标价; 把价格细分并纳入效用组合为分母; 两大日常工具之一 |
| 完美新用户 | "没用过同类竞品, 对于同类产品的旧体验为零" 的用户 (4.1.4) | ≠ 新注册用户; 旧体验为零意味着即使体验不如竞品也能赢且难被抢走 |
| 新要素 | 引入原有生产生活方式即创造新价值的东西: 新技术/人群/渠道/方法/工具/场景/认知/内容/平台等 (4.1.4, 附录) | ≠ 仅新技术; "人人都能创新, 事无大小都能创新"; 创新的本质含义 |
| 效用四分类 | 底线需求 (不能低于) / 够用就好 (不用高于) / 越多越好 (愿意多支付) / 惊喜 (超过预期或参照系) (3.2.3) | ≠ 马斯洛层次; 是满足程度的投入策略分类, 随人群情境变化 |
| bad case | "每一个 bad case, 都是一次底线不满足"; 大用户量产品后期应追求 bad case 数量最小化 (3.2.3) | ≠ 平均体验的反面; 一票否决式底线违背事件, 坏事传千里 |
| 有限理性 | "用户虽然追求理性, 但他的能力是有限的, 其判断经常出错" (2.2.1, 西蒙) | ≠ 非理性; 与系统 1/系统 2 配套; 修正理性人假设 |
| 用户五属性 | 异质性 / 情境性 / 可塑性 / 自利性 / 有限理性 (2.2.1) | 研究用户的基本口径; 可塑性含被操纵的暗面 |
| 同理心 | "能够站在别人的角度去思考, 并准确地察觉和判断别人的感受"; 天赋本能+后天适度提高 (5.1.2) | ≠ 同情/善意; 是察觉判断的准确度; A 类判据; 训练靠亲自体验 |
| 产品心 | "真的喜欢做产品……能从产品工作中感受到乐趣, 而不是功利心特别强" (5.1.2) | ≠ 职业素养; 动机纯度, 类似匠心; B 类判据之一 |
| 自省 | "发现和承认自己哪些方面较弱和哪些事做得不好"; 改善四途: 学习/合作/雇用/回避 (5.1.5) | "毫无疑问的第一潜力"; 级别越高越重要 |
| 批判性思维 | "以合理的、反思的、心灵开放的方式进行思考……反对依靠权威和流行观点" (5.2.1); 俞军口语化: "科学精神, 一个想法要经得起持续质疑和验证" | ≠ 批评态度; 源自苏格拉底问答与杜威反思性思维; "只学一个就学它" |
| 三维归因 | 产品成败从 产品经理/合作团队与企业/环境机遇 三维度还原; 判据: 特殊性/一致性/一贯性 (4.2.4) | ≠ 一维归因; "足够简化才能被系统 1 经常使用" |
| 有利可图的用户价值 | "在给定条件下, 选择满足哪些用户需求……创造'有利可图'的用户价值" (2.1); 用户价值与商业价值一体两面 | ≠ 只做赚钱功能; 引流品/跑量品/利润品并存找平衡; 全书目标浓缩 |
| 激励相容 | "使行为人追求个人利益的行为正好与企业实现整体价值最大化的目标相吻合" (3.1.2, 赫维茨) | "让对方干得好比干得不好时获得更多收入"; 机制可持续检验 |
| 双击效应 | "需求、体验碰撞到一起, 形成了双击效应 (double-killing effect)" (1.2.3) | 新要素带来海量新品需求 × 大用户量放大体验价值, 相乘解释 PM 地位 |
| 经验等级/平台匹配度/智慧等级 | "产品经理的价值 = 经验等级 × 平台匹配度 × 智慧等级" (5.1.4) | 相乘不相加; 换业务/公司匹配度清零; 智慧等级换领域保值 |
| 汉德公式 (B<PL) | 避免意外成本 B < 概率 P × 预计损失 L 时该当事人应担责 (4.4.4) | 定责看"谁避免成本更低", 非道德直觉; 平台规则工具 |
| 判责不清, 平台承担 | 价值观从"跷跷板" (偏袒一方另一方受损) 改为"弹簧" (判责分离+平台兜底); 配套"上游问题上游解决" (4.4.6) | ≠ 和稀泥; 把价值观问题转化为效率与经济的权衡 |
